# AI Chatbot

## Project Description

AI Chatbot is a Java-based chatbot application that allows users to interact with a computer program through a simple conversational interface. The chatbot processes user messages and provides appropriate responses.

## Features

- Interactive chat interface
- User input processing
- Automated chatbot responses
- Conversation between user and chatbot
- Simple and user-friendly interface
- Exit option to end the conversation

## Technologies Used

- Java
- JDK 21
- VS Code
- Object-Oriented Programming (OOP)

## How to Run

1. Open the AI Chatbot project in VS Code.
2. Open the terminal.
3. Compile the Java program using:

javac AIChatbot.java

4. Run the program using:

java AIChatbot

## How It Works

The user enters a message in the chatbot interface. The application processes the input and provides a predefined or appropriate response. The conversation continues until the user chooses to exit.

## Project Output

The chatbot displays a conversation between the user and the AI chatbot and provides responses to different user inputs.
